## Údržba dokumentace

Nové téma založte u příslušného projektu a doplňte sem odkaz. Rozhodnutí s datem, nasazené změny a otevřenou práci evidujte v plánu. U návodu udržujte dnešní umístění nastavení, ověření a způsob návratu změny. Podrobné starší testy stačí odkazovat.
